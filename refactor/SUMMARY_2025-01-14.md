# สรุปการแก้ไข Directus API Integration - Baomue Website
**วันที่: 14 มกราคม 2568**

---

## ภาพรวม

วันนี้ดำเนินการแก้ไขปัญหาการเชื่อมต่อระหว่าง Next.js Frontend กับ Directus CMS โดยมุ่งเน้นที่การแก้ไขให้ข้อมูลแสดงผลได้ถูกต้อง

---

## ปัญหาที่พบและแก้ไข

### 1. ❌ Blog Page ไม่แสดงบทความ

**ปัญหา:**
- หน้า `/blog` แสดง "Unknown error occurred"
- ใช้ nested relations (`category.*`, `featured_image.*`) ที่ทำให้เกิด error
- Thai slug ใน URL ไม่ถูก decode

**การแก้ไข (ไฟล์ `lib/data.ts`):**
```typescript
// ก่อน
fields: ['*', 'category.*', 'featured_image.*']

// หลัง - ระบุ fields แบบ explicit
fields: ['id', 'title', 'slug', 'excerpt', 'content', 'status', 
         'date_created', 'category', 'featured_image']
```

เพิ่ม decode สำหรับ Thai slug:
```typescript
export async function getBlogPostBySlug(slug: string) {
  const decodedSlug = decodeURIComponent(slug);
  // ...
}
```

### 2. ❌ Services Section บน Homepage ไม่แสดงบริการ

**ปัญหา:**
- Type mismatch: `services.category` เป็น UUID, `service_categories.id` เป็น Integer
- Services ทั้งหมดมี `category: null`
- ไม่มี tab "ทั้งหมด" สำหรับแสดงทุกบริการ

**การแก้ไข:**

**ไฟล์ `components/blocks/ServicesBlock.tsx`:**
```typescript
// เพิ่ม 'all' category รวมทุกบริการ
const servicesByCategory: Record<string, Service[]> = {};
servicesByCategory['all'] = services;

// แก้ไข comparison logic ให้รองรับ type mismatch
categories.forEach((cat) => {
  servicesByCategory[cat.slug] = services.filter((s) => {
    const serviceCategory = typeof s.category === 'object' 
      ? (s.category as any)?.id : s.category;
    return String(serviceCategory) === String(cat.id);
  });
});
```

**ไฟล์ `components/blocks/ServicesBlockClient.tsx`:**
```typescript
// เปลี่ยน default tab เป็น "all"
const [activeTab, setActiveTab] = useState<string>("all");

// เพิ่มปุ่ม Tab "ทั้งหมด"
<button key="all" onClick={() => setActiveTab("all")} ...>
  ทั้งหมด
</button>
```

### 3. ❌ Directus Authentication ล้มเหลว

**ปัญหา:**
- Static token authentication ถูก deprecate
- API calls fail เพราะไม่ได้ authenticate

**การแก้ไข (ไฟล์ `lib/directus.ts`):**
```typescript
// ใช้ email/password authentication แบบ lazy login
let isAuthenticated = false;

export async function ensureAuthenticated() {
  if (isAuthenticated) return;
  await directus.login(process.env.DIRECTUS_EMAIL!, 
                       process.env.DIRECTUS_PASSWORD!);
  isAuthenticated = true;
}
```

### 4. ❌ Field Names ไม่ตรงกับ Directus Schema

**ปัญหา:**
- Frontend ใช้ field names ที่ไม่มีอยู่ใน Directus

**การแก้ไข (ไฟล์ `lib/data.ts`):**
| Function | เดิม | แก้ไขเป็น |
|----------|------|-----------|
| `getServiceCategories` | `icon`, `color` | `icon_name` (ลบ color) |
| `getServices` | `*`, `category.*` | explicit field list |
| `getBlogPosts` | `*`, `category.*` | explicit field list |

## ปัญหาที่ยังคงอยู่

### Type Mismatch ใน Directus Schema
- `services.category` เป็น **UUID** 
- `service_categories.id` เป็น **Integer**

**ผลกระทบ:** เมื่อกดเลือก tab หมวดหมู่เฉพาะ (จัดฟัน, ความงาม) จะไม่แสดงบริการ

**Workaround:** ใช้ tab "ทั้งหมด" เป็น default เพื่อแสดงทุกบริการ

**แนะนำแก้ไขใน Directus:**
1. ไปที่ Settings > Data Model > Services
2. แก้ไข field `category` ให้เป็น M2O relationship ที่ถูกต้อง
